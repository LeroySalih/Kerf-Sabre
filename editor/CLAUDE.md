# editor/ (BISAK Kerf Editor)
TypeScript PWA for Chrome/Edge desktop. paper.js for geometry, opentype.js for text. Internal units mm; Design/Bed/Screen/Camera spaces per brief section 5; Bed→Screen conversion lives in ONE function. Edits change object matrices, never source geometry. Export DXF/SVG must work standalone. Does not talk to hardware directly (no Web Serial).

## Commands (run from `editor/`)
- `npm install`, `npm run dev` (Vite dev server), `npm run build` (typecheck + bundle), `npm test` (vitest), `npm run typecheck`.
- Machine profiles are imported from `../shared/machine-profiles` at build time (`src/machine.ts`).
- `src/coords.ts` holds Bed<->Screen conversion; do not convert elsewhere. `public/sw.js` is the offline app-shell cache.

## Modules
- `geometry.ts` (segments/matrices/shapes), `select.ts` (box select), `clipboard.ts` (strict parse of pasted Kerf clips; copy/paste uses the browser clipboard events), `align.ts` (align/distribute; groups are one unit), `boolean.ts` (union/intersect/subtract via paper.js; Bezier results are fitted back to true arcs, preferring the input circles; groups and text are compound operands), `gizmo.ts` (gimbal handle layout, hit-testing and drag maths; matrices are set from drag-start snapshots), `text.ts` (text to paths: DejaVu outline fonts via opentype.js laid out glyph by glyph, Hershey single-line fonts; live text objects are `textId` contours in `Doc`, regenerated by `retext`, flattened by `convertText`), `snap.ts` (snap planner; object snaps beat the grid), `ruler.ts` (ruler ticks, measure), `bounds.ts` (out-of-bed check, canSubmit), `status.ts` (footer text), `trim.ts` (trim: pure planner, bakes placement into the kept paths), `anchor.ts` (3x3 anchor, numeric X/Y position and W/H resize, scale % and rotate, all about the anchor), `doc.ts` (objects + undo/redo), `export.ts` (DXF/SVG), `dxf-import.ts` (LINE, ARC, CIRCLE, LWPOLYLINE, POLYLINE, SPLINE), `main.ts` (UI).
- Import only converts and normalises (units -> mm; a file with no `$INSUNITS` is assumed to be centimetres, the Onshape default; bbox bottom-left -> 0,0). Dedupe/merge/join clean-up is Server work. Unsupported entities (TEXT, HATCH, ELLIPSE...) are counted and reported, not imported.
- Groups are a `group` id on `DocObject` (one level; grouping again merges). Selection and moves always go through `Doc.expand()` so group members act together. The 1 cm grid is drawn by `drawGrid` in `main.ts` (toggle in the toolbar).

## Fonts
`public/fonts/` holds DejaVu (free licence, see DEJAVU-LICENSE.txt). `src/fonts/hershey.json` is a subset of the Hershey single-line fonts via the MIT-licensed hersheytext package (HERSHEYTEXT-LICENSE.txt). opentype.js 2.x has no types (`src/opentype.d.ts`) and throws on some GSUB tables, so never call `font.getPath(text)`; lay out per glyph.
