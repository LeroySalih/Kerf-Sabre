# editor/ (BISAK Kerf Editor)
TypeScript PWA for Chrome/Edge desktop. paper.js for geometry, opentype.js for text. Internal units mm; Design/Bed/Screen/Camera spaces per brief section 5; Bed→Screen conversion lives in ONE function. Edits change object matrices, never source geometry. Export DXF/SVG must work standalone. Does not talk to hardware directly (no Web Serial).

## Commands (run from `editor/`)
- `npm install`, `npm run dev` (Vite dev server), `npm run build` (typecheck + bundle), `npm test` (vitest), `npm run typecheck`.
- Machine profiles are imported from `../shared/machine-profiles` at build time (`src/machine.ts`).
- `src/coords.ts` holds Bed<->Screen conversion; do not convert elsewhere. `public/sw.js` is the offline app-shell cache.

## Modules
- `geometry.ts` (segments/matrices/shapes), `select.ts` (box select), `tabs.ts` (tabs/bridges: stored on `DocObject.tabs` as fractions along the closed Cut outline plus a width in mm; `splitByTabs` turns them into the open pieces the laser cuts, applied in DXF/SVG export and, later, G-code), `repair.ts` (join loose segments into paths with a bucketed tolerance match, close, explode, and node move/insert/delete; DXF import auto-joins per layer), `fillet.ts` (also `roundedRectangle`; corner radius/chamfer of straight-line corners as true arcs; clamps to half of each edge), `icons.ts` (tool icon set + sprite), `arrays.ts` (linear repeat, circular array, mirror), `testgrid.ts` (material test grid and kerf coupon generators; cells record per-shape power/speed in `DocObject.settings`), `dialog.ts` (native <dialog> parameter form), `presets.ts` (placeholder material presets + per-laser resolution), `clipboard.ts` (strict parse of pasted Kerf clips; copy/paste uses the browser clipboard events), `align.ts` (align/distribute; groups are one unit), `boolean.ts` (union/intersect/subtract via paper.js; Bezier results are fitted back to true arcs, preferring the input circles; groups and text are compound operands), `gizmo.ts` (gimbal handle layout, hit-testing and drag maths; matrices are set from drag-start snapshots), `text.ts` (text to paths: DejaVu outline fonts via opentype.js laid out glyph by glyph, Hershey single-line fonts; live text objects are `textId` contours in `Doc`, regenerated by `retext`, flattened by `convertText`), `snap.ts` (snap planner; object snaps beat the grid), `ruler.ts` (ruler ticks, measure), `bounds.ts` (out-of-bed check, canSubmit), `status.ts` (footer text), `trim.ts` (trim: pure planner, bakes placement into the kept paths), `anchor.ts` (3x3 anchor, numeric X/Y position and W/H resize, scale % and rotate, all about the anchor), `doc.ts` (objects + undo/redo), `export.ts` (DXF/SVG), `dxf-import.ts` (LINE, ARC, CIRCLE, LWPOLYLINE, POLYLINE, SPLINE), `main.ts` (UI).
- Import converts, normalises and auto-joins touching entities per layer (units -> mm; a file with no `$INSUNITS` is assumed to be centimetres, the Onshape default; bbox bottom-left -> 0,0). Dedupe/overlap-merge clean-up is Server work (join is done here too, so the editor works standalone). Unsupported entities (TEXT, HATCH, ELLIPSE...) are counted and reported, not imported.
- Groups are a `group` id on `DocObject` (one level; grouping again merges). Selection and moves always go through `Doc.expand()` so group members act together. The 1 cm grid is drawn by `drawGrid` in `main.ts` (toggle in the toolbar).

## Server (Send to server)
`server.ts` is the API client (bearer token + address kept in localStorage; errors become readable `ServerError`s), `job.ts` builds the job document from the objects (tab fractions become `atLengthMm` in bed space after the matrix; arcs keep their direction as `clockwise`), `serverui.ts` holds the top-bar buttons: Sign in, Send to server (placement: where the laser head is, with an anchor, or exactly where drawn on the bed), My files (status, send a draft, cancel). On sign-in the material list is replaced by the server's presets (`presetStore` in `presets.ts`). When the Editor is served by the server the address is blank (same origin); under `npm run dev` enter the server address and set `KERF_CORS_ORIGINS=http://localhost:5173` on the server. Station mode (frame / start) is not built yet.

## Fonts
`public/fonts/` holds DejaVu (free licence, see DEJAVU-LICENSE.txt). `src/fonts/hershey.json` is a subset of the Hershey single-line fonts via the MIT-licensed hersheytext package (HERSHEYTEXT-LICENSE.txt). opentype.js 2.x has no types (`src/opentype.d.ts`) and throws on some GSUB tables, so never call `font.getPath(text)`; lay out per glyph.

## Layout (LightBurn-style)
`index.html` + `src/style.css`: top bar (file, history, edit, view, Tools menu, laser), left two-column tool palette holding EVERY tool and action as an icon button (draw, edit, boolean, arrange, align, repeat; icons live in `src/icons.ts` and are injected as an SVG sprite, `tests/icons.test.ts` checks every icon is used, every button has a tooltip and aria-label), canvas centre, right sidebar (Properties, Options, Cuts / Layers), bottom bar (Cut/Score layer chips + material picker with locked settings), footer (selection size, notices, cursor). Element ids are the contract with `main.ts`: keep them when moving things around.
- The layer chips set the layer for NEW shapes (`activeLayer`) and move the current selection onto that layer.
- `presets.ts` holds PLACEHOLDER presets in the shape of `shared/preset.schema.json` (a test validates them against it); `resolvePreset` applies per-laser overrides and flags untested lasers. The chosen preset id lives in `Doc.state.materialId`. Pupils see the settings locked.

- Palette actions disable themselves when they cannot apply (`refreshActions` in `main.ts`): booleans/group need 2+ shapes, space needs 3+, etc.
